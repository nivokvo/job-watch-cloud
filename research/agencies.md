# Работодатели вакансий вроде «Аудитора сети аптек»

Проверено 5 октября 2026 г. Данные rabota.by взяты из `HH-Lux-InitialState`: 55 поисковых запросов по всей Беларуси (area=16), из них 16 только по удалёнке. Каждый employer_id проверен на странице `rabota.by/employer/ID`. Полный список с примерами лежит в `agencies.json`.

## Выводы

1. **Сейчас клонов эталона на rabota.by нет.** По запросам «аудитор аптек», «мониторинг наличия», «тайный покупатель», «ритейл аудит» находятся мерчендайзеры с выездами, финансовые аудиторы или шум. Эталон был редкой разовой вакансией, поэтому ловить его нужно по employer_id, а не по тексту.
2. **У SPECSERVICE два юрлица.** «Спецсервис персонал» (5224800) и «Ритейл Мониторинг» (2731472, сайт bravo-btl.by): описание на rabota.by совпадает слово в слово, а вакансию «Ритейл Мониторинга» в Жодино подписывает «Компания SPECSERVICE» и упоминает «аудит аптек 1 раз в 3 месяца». Сторож сейчас смотрит только 5224800, второй ID надо добавить.
3. **Ближе всего к «80% делает автоматизация» Data Light (11057529).** Удалённо: проверка описаний изображений и видео, сбор инфографики, авторы математических задач (подходит студенту мехмата). 20 активных вакансий, новые каждую неделю. Минусы: компания российская, оплата в рублях, ГПХ с самозанятым или ИП, от 4 ч в день, по 1000-3500 откликов. Есть и вакансия с телефонными опросами, её отсекать.
4. Остальные агентства мерчендайзинга и аудита (СКайМерч, MS services, ANCOR, Нильсен, МАСМИ) нанимают редко и почти всегда для работы в магазинах, по rubric.md это максимум 3. Их стоит держать в отдельном фильтре: вдруг появится разовый аудит «по сайтам».
5. У ритейлеров (Евроторг: мониторинг цен, Евроопт онлайн: качество поиска, ОМА: ввод карточек) работа по сути подходящая, но это офис и полный день. В будни с 8 до 16 это максимум 3.
6. Тайных покупателей набирают через анкеты на своих сайтах (Active Sales), а не через rabota.by. По rubric.md это максимум 2. Глеб нигде не регистрируется.

Один URL на все агентства, проверено, что несколько employer_id работают:

```
https://rabota.by/search/vacancy?employer_id=5224800&employer_id=2731472&employer_id=5711279&employer_id=5778201&employer_id=772397&employer_id=836438&employer_id=763845&order_by=publication_time
```

Сейчас по нему 22 вакансии, все с выездами. Data Light лучше смотреть отдельно, а фильтровать по названию на стороне сторожа: текстовый `text=` по этому работодателю ничего не отсекает (20 из 20).

```
https://rabota.by/search/vacancy?employer_id=11057529&order_by=publication_time
```

По названию отбрасывать «опрос», «разработчик», «Engineer», «на … языке» (нужен язык, которого у Глеба нет).

В стоп-лист: «Бренд Скан Бай» (8986978, панель опросов ThinkLink.by), «Оператор телефонных опросов», «промоутер», «интервьюер» на точках продаж.

## Как считалась частота

API hh (`api.hh.ru`) отвечает 403. В поиске rabota.by дата публикации означает дату поднятия, поэтому возраст вакансии оценивал по ID. Вакансия 135663348 опубликована 4 августа, 138126149 сегодня, это около 40 тыс. ID в день. Архивные вакансии открываются по прямой ссылке, но их списка по работодателю нет, поэтому «как часто» оценено по активным вакансиям за последние 1-2 месяца.
